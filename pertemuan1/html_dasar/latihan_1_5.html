Daftar Link dengan Atribut Target

  • Halaman PNM
  • Halaman List
  • Halaman Paragraf
  • Halaman Heading
  • Halaman Bentukan Heading dan Paragraf

Kesimpulan

  • Saat mengklik link dengan atribut _self, halaman akan terbuka di jendela/tab yang sama.
  • Saat mengklik link dengan atribut _blank, halaman akan terbuka di tab atau jendela baru.
  • Saat mengklik link dengan atribut _parent, jika halaman berada dalam iframe, link akan terbuka di frame induk.
  • Saat mengklik link dengan atribut _top, jika halaman berada dalam frame, link akan terbuka di seluruh jendela browser, menghapus semua frame.
